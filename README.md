# ms-taq-man

A browser arcade game where Taq polymerase races through DNA template mazes, collects RNA primers, and synthesizes a double-helix trail while avoiding nucleases and inhibitors. Clear a cycle by covering half the template or collecting every primer.

See [docs/USAGE.md](docs/USAGE.md) for controls, scoring, and sound settings.
